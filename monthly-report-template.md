# Monthly report template

Send this in the last week of each month. Keep it to one page: founders read the summary and the decisions, and skim the rest.

---

```
# LinkedIn report: [Month Year]
Prepared for [Founder name] · [Date]

## Summary (3 lines)
- [Headline result, e.g. "Best month yet: 112K impressions, 3x last month"]
- [Business signal, e.g. "4 inbound DMs from CTOs, 1 booked call"]
- [Main decision for next month, e.g. "More buyer-education posts; add a follow CTA"]

## Numbers
| Metric                      | This month | Last month | Change |
|-----------------------------|-----------:|-----------:|-------:|
| Posts published             |            |            |        |
| Impressions                 |            |            |        |
| Members reached             |            |            |        |
| Out-of-network share        |            |            |        |
| Reactions                   |            |            |        |
| Comments                    |            |            |        |
| Comments per 100 reactions  |            |            |        |
| Saves                       |            |            |        |
| Profile viewers             |            |            |        |
| New followers               |            |            |        |
| Custom button clicks        |            |            |        |
| Inbound DMs / leads         |            |            |        |

## Top 3 posts (by comments and profile views)
1. "[Hook]" · [impressions] · [comments] · why it worked: [one line]
2. ...
3. ...

## What we learned
- [e.g. Story posts got 2x the comments of how-to posts]
- [e.g. Tuesday posts reached more people than Friday posts]

## Business impact
- [DMs, calls, leads, hires, partnerships, invitations that came from LinkedIn]

## Next month
- Focus pillars: [..]
- Posts planned: [12]
- Experiments: [e.g. first carousel; follow CTA on 3 posts]
- From you: [e.g. 2 client stories; approval by Wednesdays]
```

---

## Tips

- **Lead with business impact**, not impressions. DMs and calls matter more to founders than reach.
- **Always compare** to last month and to the first month. Founders forget where they started.
- **Be honest about flops.** Explain what you learned and what you'll change.
- Copy the numbers straight from the "Weekly summary" sheet in [`ghostwriting-tracker.xlsx`](ghostwriting-tracker.xlsx).
