# Profile optimisation

Great posts send people to the founder's profile. If the profile doesn't say who they help and what to do next, that attention is wasted. Fix the profile **before** the first post.

## Checklist

| Element | What good looks like | Done |
|---|---|---|
| Photo | Face fills ~60% of the frame, plain or soft background, recent | ☐ |
| Banner | Says who you help + proof or a CTA (template below) | ☐ |
| Headline | Who you help + the outcome + proof (formulas below) | ☐ |
| About | Hook, problem, how you help, proof, CTA (template below) | ☐ |
| Featured | 1 offer, 1 case study or proof, 1 best post | ☐ |
| Custom button | "Book an appointment" or "Visit my website" (needs LinkedIn Premium) | ☐ |
| Experience | Current role describes outcomes for clients, not duties | ☐ |
| Contact info | Website and email filled in | ☐ |
| Follow vs connect | Primary button set to "Follow" if the founder posts publicly | ☐ |

## Headline formulas

LinkedIn headlines can be up to 220 characters, but only the first ~60–70 show in many places. **Put the most important words first.**

| Formula | Example (fictional) |
|---|---|
| I help [who] [achieve outcome] | I help mid-sized companies cut cloud bills and stop outages · CEO, CloudHarbor |
| [Role] · [who you serve] · [proof] | Founder, CloudHarbor · Managed cloud & security for US mid-market · 120+ clients since 2015 |
| [Outcome] for [who] \| [Role] | Boring, reliable cloud for growing companies \| CEO @ CloudHarbor |

❌ Avoid: "CEO at CloudHarbor" alone, or a list of buzzwords ("Visionary | Leader | Innovator").

## About section template

The About section can be up to 2,600 characters. Only the first ~3 lines show before "see more", so start strong.

```
[Hook: one line about the problem your buyer has.]
Most mid-sized companies pay 20–40% more for cloud than they need to, and find out during an outage.

[Who you help and how]
I run CloudHarbor. We manage cloud infrastructure and security for US companies with 50–500 people,
so their IT team can stop firefighting and plan ahead.

[What you do, as 3–5 bullets]
✅ Cloud cost reviews and right-sizing (AWS, Azure)
✅ 24/7 monitoring and incident response
✅ Security audits and compliance prep (SOC 2, HIPAA)

[Proof]
Since 2015: 120+ clients, 99.98% average uptime, and an average 31% cut in cloud bills in year one.

[Personal line]
Before CloudHarbor I spent 10 years as an infrastructure engineer, so I've been the one paged at 3 am.

[Call to action]
I post about cloud costs, security and running an IT company 3x a week. Follow for practical lessons,
or DM me "audit" for a free 20-minute cloud cost check.
```

## Featured section: what to pin

1. **Your offer**: a link to a booking page or service page, with a clear title ("Free 20-min cloud cost check")
2. **Proof**: a case study, client result or press mention
3. **Your best post**: the one with the most comments, not just impressions

## Banner template

Canvas size: **1584 × 396 px**. Keep text away from the left third (the profile photo covers it on mobile).

```
[Left third: empty or brand colour]
[Centre/right:]  Managed cloud & security for growing US companies
                 120+ clients · 99.98% uptime · cloudharbor.example
```

## Custom button

With LinkedIn Premium, add a custom button to the profile intro (for example "Book an appointment" linking to a booking page). Track clicks weekly; they show buyer intent. In the real case study behind this kit, the custom button got **13 clicks** in one strong week.
